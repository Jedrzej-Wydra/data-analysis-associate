# Associate Data Analyst Exam by DataCamp

#### author: Jędrzej Wydra

![Data Analyst Badge](DA.png)

## Short summary
Performed statistical exploration and hypothesis testing in R to analyze the relationship between product pricing, sales volume, and repeat purchase behavior using visual analytics and variance-based tests.

## Technical summary
Built an R-based workflow with tidyverse for data preprocessing, feature binning, and grouping, then applied t-tests, Wilcoxon tests, and Bartlett’s variance test to evaluate differences between customer segments. Visualized key distributions and interactions with ggplot2, summarizing group-level statistics to assess patterns behind repeat buying behavior. Designed a fully reproducible EDA pipeline focused on categorical segmentation and variance-driven statistical inference.
